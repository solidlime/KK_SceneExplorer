# KK_SceneExplorer（Koikatsu Studio シーンエクスプローラー）

Koikatsu Studio のシーン参照先にネットワークドライブ（NAS 等）を追加し、シーンをブラウズ・読み込み・保存できる BepInEx プラグインです。

ファイルブラウザ UI（シーンツリー・グリッド表示・サムネイル・ソート・削除・インポート）を搭載し、ゲーム標準のシーン一覧を置き換えます。

## 機能

- **NAS / ネットワークフォルダ参照**：`\\nas\scenes` のような UNC パスや割当ドライブ（`Z:\`）をシーンの追加参照先として登録できます（複数登録可）。
- **シーンブラウザ UI**：サムネイル表示・ファイル名/日時/サイズのソート・ツールチップ・サムネイルサイズ調整（48〜600px）に対応したシーン一覧ウィンドウ。
  - 左ペインのツリーでローカル（`UserData\studio\scene`）とネットワークフォルダを同じ階層でブラウズできます。
  - シーンはダブルクリックで読み込み、選択してロード／インポート／削除（二段階確認）ができます。
- **読み込んだシーンのフォルダへ保存転送**：シーン保存は常にローカルで行われた後、**最後に読み込んだシーンのフォルダ**がネットワークフォルダの場合のみ自動で転送されます。パス正規化に対応しており、KK_CardCompression を挟んでも正しい保存先に転送されます。
- **KK_CardCompression 共存**：KK_CardCompression（KKCC）導入済み環境では、KKCC の圧縮完了（ファイルサイズ変化）を待ってから転送します（最大 60 秒待機、タイムアウト時は未圧縮のまま転送）。KKCC 未導入環境ではそのまま転送します。
- **BrowserFolders 共存**：BrowserFolders 導入環境では BF のシーンツリーを無効化し、本プラグインのツリーを使用します（BF 未導入でも同じツリーが使えます）。
- **設定キーで開閉**：デフォルト `Ctrl+F9` でブラウザを開閉します（キーは設定で変更可）。

## インストール

1. BepInEx 5.x が導入された Koikatsu（または Koikatsu！Sunshine）を準備します。
2. `bin\Release\KK_SceneExplorer.dll` を `BepInEx\plugins\` にコピーします。
3. ゲームを起動して Studio を開くと有効になります。

## 設定

設定ファイル `BepInEx\Config\KK_SceneExplorer.cfg`（ゲーム内で設定 UI から変更した内容が保存されます）。

| キー | デフォルト | 説明 |
|------|------------|------|
| `SceneFolders` | （空） | ネットワークシーンフォルダ。セミコロン区切りで複数指定可。例: `Z:\koikatsu_scenes;\\nas\scenes` |
| `SettingsKey` | `F9 + LeftControl` | ブラウザの表示切替キー |
| `FontSize` | `14` | ブラウザのフォントサイズ（8〜32） |

- ゲーム内では `Ctrl+F9` で設定ウィンドウが開きます（フォルダの追加・削除・フォントサイズ変更は即時反映）。
- パスの入力はスラッシュ（`/`）区切りで行ってください（例: `//nas/scenes`）。保存時に自動でバックスラッシュ形式に変換されます。
- ドライブレターがゲームから見えない場合（管理者権限起動など）は、ドライブレター（`B:\`〜）ではなく UNC パス（`\\nas\scenes`）を指定してください。

## 使い方

1. Studio で「シーンを開く」を開くと、ゲームのシーン一覧の代わりに本プラグインのブラウザが表示されます（`Ctrl+F9` でも開閉可）。
2. 左ペインのツリーでフォルダを選択すると、そのフォルダのシーンが右ペインの一覧に表示されます。
3. シーンをダブルクリック（または選択してロード）で読み込みます。
4. 保存すると、読み込んだシーンのフォルダに自動で保存転送されます。

## 動作環境・依存

- ゲーム: Koikatsu（KK）/ Koikatsu！Sunshine（KKS）※コードは共通ですが KKS は未検証
- フレームワーク: BepInEx 5.x
- 任意: KK_CardCompression（あれば圧縮対応）、BrowserFolders（あればツリーを無効化して共存）

## 既知の制限・注意

- ネットワークフォルダへのアクセスはゲームの実行権限に依存します。ネットワーク切断時は、そのフォルダのシーンが一覧から消えるだけでクラッシュしません。
- ネットワークフォルダへの保存転送に失敗した場合は、シーンはローカル（`UserData\studio\scene`）に残ります。
